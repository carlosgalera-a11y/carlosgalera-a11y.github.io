Copias de seguridad

← FileHub

Cada sesión de Claude Code, Cursor u opencode sube aquí el código que ha generado, cifrado, al repositorio privado filehub-backups. Esta página no guarda ningún dato: pide el acceso cada vez que la abres en un navegador nuevo.

Acceso

Créalo en GitHub → Settings → Developer settings → Fine-grained tokens, dándole acceso solo a filehub-backups con permiso Contents: read-only. Se guarda en este navegador y en ningún sitio más.

NAS por Tailscale

Lee nas-media.tail3a7cac.ts.net directamente. Es la misma copia cifrada que hay en GitHub, pero en disco propio. La clave se guarda en este navegador; nunca viaja al repositorio ni está escrita en esta página.

Restaurar desde el terminal

CLAVE=$(security find-generic-password -s copias-codigo-claude -w)

gh api "repos/carlosgalera-a11y/filehub-backups/contents/sesiones/FICHERO.tar.gz.enc" \
  -H "Accept: application/vnd.github.raw" > c.enc

openssl enc -d -aes-256-cbc -pbkdf2 -in c.enc -out c.tar.gz -pass "pass:$CLAVE"
mkdir x && tar -xzf c.tar.gz -C x
git clone x/cambios.bundle repo-restaurado

Una copia completo se restaura sola. Una incremental solo trae los commits nuevos: clona primero el «completo» más antiguo de ese proyecto y aplica encima los incrementales con git pull ../x/cambios.bundle en orden de fecha.
